# Synapse CLI — все команды из гайда участника

Запускать из папки `app` (там код, который сканирует Synapse). Скрипты `*.bat` рядом делают это сами.

## Основные

| Команда | Что делает |
|---|---|
| `npm install -g @2ndbrainlabs-ai/synapse-cli` | установка (Node.js 20+) |
| `synapse --version` | проверка установки |
| `synapse init` | инициализация проекта, ввод ключа API из Synapse console (для hosted-сборки) |
| `synapse build` | сканирование кода и генерация MCP-сервера (меню: Auto или Custom) |
| `synapse build --auto --all-endpoints` | Auto, все найденные маршруты, без меню |
| `synapse build --auto --endpoints "GET /a,POST /b"` | Auto, только перечисленные маршруты |
| `synapse build --custom -q "<описание>"` | Custom: один инструмент по описанию (только Python) |
| `synapse build --smart-names` | понятные имена и описания инструментов (только Auto) |
| `synapse build --discover` | пересканировать после изменений кода (тот же MCP-сервер) |
| `synapse build --resume` | продолжить прерванную сборку |
| `synapse build --new` / `--server-name <name>` | второй сервер / выбрать сервер |
| `synapse build --local` | сборка своей моделью: без аккаунта Synapse, без квоты, код не уходит в Synapse |
| `synapse model set <provider>` | выбрать провайдера модели для `--local` |
| `synapse model` | какой провайдер и ключ будут использованы и откуда ключ |
| `synapse info` | состояние проекта и остаток квоты |
| `synapse config` | какой API-ключ используется и откуда взят |

## Провайдеры для `--local` (`synapse model set <id>`)

| Провайдер | id | Переменная с ключом |
|---|---|---|
| Anthropic (по умолчанию) | `anthropic` | `ANTHROPIC_API_KEY` |
| OpenAI | `openai` | `OPENAI_API_KEY` |
| Groq | `groq` | `GROQ_API_KEY` |
| xAI (Grok) | `xai` | `XAI_API_KEY` |
| OpenRouter | `openrouter` | `OPENROUTER_API_KEY` |
| Ollama | `ollama` | не нужен |
| Amazon Bedrock | `bedrock` | ваши учётные данные AWS |
| Google Vertex AI | `vertex` | учётные данные Google Cloud |
| Свой адрес | `custom` | `SYNAPSE_LLM_API_KEY` (необязательно) |

В Windows вместо `export` из гайда: `setx ANTHROPIC_API_KEY "sk-ant-..."` (и новое окно) или `set ANTHROPIC_API_KEY=...` в текущем окне.

## Ограничения локального режима

- Сгенерированный код (`synapse_auto_server.py`) получают только Python-проекты — наш как раз Python.
- Слабые локальные модели могут не справиться со схемой; ошибка `returned no emit_tool_plan call` — взять модель сильнее.

## Подключение к MCP-клиенту

После сборки Synapse печатает готовый JSON — вставьте его в конфиг клиента и перезапустите клиент.

- Hosted-сборки файлов не пишут: фрагмент запускает `@2ndbrainlabs-ai/synapse-mcp` через `npx` с вашим `SYNAPSE_SERVER_ID`. Пересборка сохраняет ID — конфиг менять не нужно.
- `--custom` и `--local` пишут Python-сервер в проект (`<tool_name>_server.py` или `synapse_auto_server.py`) — клиент указывает на этот файл.
- **Claude Desktop:** Settings → Developer → Edit Config, вставить в `mcpServers` (файл `%APPDATA%\Claude\claude_desktop_config.json`).
- **Cursor:** Settings → MCP → добавить сервер с этой командой.
- Любой другой MCP-клиент — туда, где он перечисляет `mcpServers`.

Перед запуском агента API должен работать (`Запустить_API.bat`, http://127.0.0.1:9100/docs).

## Советы из гайда

- Квота бесплатного тарифа: 10 MCP-серверов и 100 000 проиндексированных строк. Пересборка без изменений бесплатна, `--local` не считается.
- Открывайте только то, что нужно агенту: меньше хорошо названных инструментов — надёжнее агент.
- Секреты не в коде: заголовки уходят как `${ENV}`-заглушки, токены держите в переменных окружения.
- Hosted Auto отправляет имена маршрутов, пути и docstring; `--smart-names` и Custom — ещё и код функций. Для чувствительного кода — `--local`.
- Отключить телеметрию: `SYNAPSE_TELEMETRY=0` (скрипты это делают).

## Частые ошибки

| Сообщение | Что делать |
|---|---|
| `Not Initialized` | выполнить `synapse init` |
| `Quota Exceeded` | `synapse info`, или собрать с `--local` |
| `AUTH_INVALID` | сохранить верный ключ: `synapse config set-key` |
| `Endpoint Selection Required` | добавить `--all-endpoints` или `--endpoints <список>` |
| `returned no emit_tool_plan call` | локальная модель слишком слабая — взять сильнее |
| `SERVER_ERROR` | ошибка на стороне Synapse — сообщить им с `Session: id` |
