# Как подать GeoVision на Vibe-a-thon (трек 1)

Папка `Hackathon_GeoVision` — отдельная безопасная копия бэкенда GeoVision для хакатона.
Рабочий GeoVision (`C:\Meteo_1.4\GeoVision`) она не трогает: свой порт 9100, та же база, но роль только на чтение.

## 0. Перед подачей

- [ ] **Согласовать с руководством КГС** участие с этим проектом: каталог KazEOSat, облачность и код — разработка КГС.
- [ ] Решить, что показывать в репозитории: код этой папки чистый (без паролей, данных, моделей), но описывает внутренний сервис.

## 1. Запустить API

`Запустить_API.bat` → откроется http://127.0.0.1:9100/docs. Там 5 маршрутов — это и есть «legacy app».
Окно не закрывать, пока работает агент.

## 2. Установить Synapse

`synapse\1_install_synapse.bat` (Node.js 22 уже есть).

## 3. Собрать MCP-сервер — один из вариантов

**B. Локально (рекомендую: код не уходит в Synapse, квоты нет).**
1. Нужен ключ Anthropic API (console.anthropic.com). Один раз: `setx ANTHROPIC_API_KEY "sk-ant-..."` в cmd, затем открыть новое окно.
2. `synapse\4_build_local.bat` → появится `app\synapse_auto_server.py`.

**A. Hosted (как в основном сценарии гайда).**
1. Получить ключ в Synapse console → `synapse\2_init_project.bat` (вставить ключ в окно).
2. `synapse\3_build_auto_hosted.bat` (или `3b_...smart_names.bat` — понятнее имена инструментов).

Оба варианта открывают агенту только 5 маршрутов на чтение.

## 4. Подключить к Claude Desktop

Synapse напечатает JSON-фрагмент → Claude Desktop → Settings → Developer → Edit Config → вставить в `mcpServers` → перезапустить Claude Desktop. Проверить, что инструменты GeoVision видны.

## 5. Прогнать и записать демо

Сценарий и промпты — `demo\tasks.md` (3 задачи + показ безопасности). Зоны — `demo\zones\*.geojson`.
Запись экрана: OBS или Win+G. Показать вызовы инструментов агентом.

## 6. Репозиторий для сдачи

```bat
cd C:\Meteo_1.4\Hackathon_GeoVision
git init
git add .
git status            & rem убедиться, что app\.env НЕТ в списке
git commit -m "GeoVision Catalog API + Synapse MCP"
```
Затем создать репозиторий на GitHub и запушить. В репозиторий должны попасть сгенерированные Synapse файлы
(`synapse_auto_server.py` или конфиг) — это требование трека («the generated MCP setup»). Перед коммитом
откройте их и проверьте, что там нет ключей.

## 7. Что сдать (по гайду, трек 1)

1. Ссылка на репозиторий.
2. Сгенерированная MCP-настройка (в репозитории + JSON-фрагмент из шага 4 без ключей).
3. Видео: агент выполняет ≥ 3 реальные задачи, код приложения не меняется.

Оценивают: насколько полезны задачи, какие маршруты открыты и почему (раздел «Endpoint selection» в README.md),
насколько надёжно агент выполняет задачи.

## Что сделано для безопасности

| Что | Как |
|---|---|
| Пароли | только в `app\.env` (в `.gitignore`); в репозитории `app\.env.example` |
| Запись в базу | роль `geovision_ro`: только SELECT, транзакции только на чтение; `CATALOG_REFRESH=0` |
| Опасные маршруты | убраны: запись файлов, загрузка/удаление прогнозов, GPU-расчёт, старый KML-маршрут |
| Корпоративные данные | нет Excel с облачностью, моделей U-Net, квиклуков, путей к файлам в ответах |
| Код в Synapse | вариант `--local` — код остаётся на ПК |
